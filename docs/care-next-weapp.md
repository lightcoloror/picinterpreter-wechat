# 图语家小程序患者协作接入

更新时间：2026-09-13 20:14:08（Asia/Shanghai）
实现与整理：Codex（GPT-6 Astra）

## 接入

构建开关 `TARO_APP_CARE_COLLABORATION=true`；服务端同时使用本轮 CARE_COLLABORATION_ENABLED、CARE_NEXT_ENABLED。沿用现有登录入口、User ID 和 Taro 页面。患者进入表达页，家属进入接收页；设置管理与使用角色分开。

`taroCareContext` 提供账号/家庭/患者分区；`taroCareRuntime` 提供文件、网络、加密归档、生命周期适配；`taroCareWorkspace` 把共享 careSync 投影到实际图库、收藏、偏好和人工顺序。恢复前台、联网、保存和前台 30 秒检查触发同步。投影不会覆盖新产生的待保存修改；保存竞态有专用回归测试。

档案设置页复用共享 CarePanel。个人收藏原件和家庭共享不是公共模板；选中的额度来源随请求发送，额度不足不会换扣其他家庭。语音、设备布局覆盖和普通历史留在本机，默认保留最近 50 条完成沟通。新版不会沿旧接收记录接口上传历史。

## 换设备

设置页密码加密导出，空白设备的协作设置页离线导入并确认来源。保留同一患者和稳定资源 ID，不携带会话或授权。离线恢复后仍可进入表达、接收并再次导出。联网登录后需明确选择同一患者再恢复，先鉴权并核对删除标记。公共模板沿现有浏览/应用流程使用，不由收藏更新接口修改。
